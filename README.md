# Shell-emulator

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной
файловой системой (VFS). Учебная практическая работа.

## Стек
- Python 3.10+
- PyQt6 (графический терминал)

## Запуск
`./run.sh` или `run.bat` (из корня репозитория).

## Структура
- `src/` — исходный код приложения;
- `tests/` — тесты pytest;
- `scripts/` — скрипты реальной ОС и стартовые скрипты эмулятора;
- `vfs/` — XML-источники виртуальной файловой системы.

Работа ведётся поэтапно в ветках `stage_one`, `stage_two`, `stage_three`, `stage_four`, `stage_five`.
